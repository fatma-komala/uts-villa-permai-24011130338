## Deskripsi Project

Villa Permai merupakan aplikasi pemesanan villa berbasis web yang dibuat untuk memudahkan calon tamu dalam melihat informasi villa, memeriksa ketersediaan, dan menghitung biaya penginapan secara otomatis.

Website ini dibuat menggunakan HTML, CSS, dan JavaScript tanpa menggunakan back-end maupun database.

## Fitur Website

### Fitur yang Sudah Dibuat

1. Menampilkan tiga pilihan villa.
2. Menampilkan tipe kamar, lokasi, harga, fasilitas, dan status villa.
3. Pencarian villa berdasarkan nama dan fasilitas.
4. Formulir pemesanan villa.
5. Dropdown pilihan villa otomatis.
6. Perhitungan total biaya berdasarkan harga per malam dan jumlah malam.
7. Validasi nama, tanggal check-in, check-out, dan jumlah tamu.
8. Pemeriksaan jadwal pemesanan.
9. Penyimpanan pesanan menggunakan localStorage.
10. Menampilkan riwayat pesanan.
11. Tampilan responsif untuk laptop, tablet, dan ponsel.

### Fitur yang Belum Dibuat

1. Pembayaran online.
2. Konfirmasi pemesanan melalui WhatsApp secara otomatis.
3. Pengelolaan pesanan oleh administrator.
4. Sinkronisasi data pemesanan antarperangkat.

## Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder `uts-villa-permai`.
3. Buka file `index.html` menggunakan browser.
4. Website Villa Permai dapat langsung digunakan tanpa instalasi aplikasi tambahan.
